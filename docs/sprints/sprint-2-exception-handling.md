# 🛡️ Sprint 2: PRD 5대 예외 처리 및 방어 로직 완벽 구현

## 📋 스프린트 목표
PRD Section 5에 명시된 5가지 필수 방어 로직을 조건문과 이벤트 핸들러 형태로 빈틈없이 구현합니다.

---

## 🛠️ 세부 작업 항목 (Tasks)

### 1. [예외 1] 태그 매칭 실패 및 수동 변경 우선순위 보호
- [ ] 딕셔너리 매칭 실패 시 기본 텍스트 `미지정` 표출
- [ ] 태그 칩 클릭 시 7개 부위 선택 팝오버 표시
- [ ] 수동 변경 시 `isManualTagged: true`로 설정하여 이후 운동명 변경 시에도 태그 보존

### 2. [예외 2] 운동명 누락 시 세트/무게 입력 시도 차단 & 1.5초 레드 깜빡임
- [ ] 아코디언 내부의 무게(weight) 및 횟수(reps) 입력 필드 `onFocus` 시 핸들러 연결
- [ ] `exercise.name.trim() === ''`인 경우:
  - 입력 필드 포커스 취소 (`event.target.blur()`)
  - 운동명 인풋에 1.5초간 붉은색 테두리 깜빡임(`animate-pulse` 또는 커스텀 `@keyframes red-blink`) 적용
  - 운동명 인풋으로 강제 포커스 이동 (`nameInputRef.current?.focus()`)
  - 토스트 또는 인라인 안내 메시지 표시

### 3. [예외 3] 마지막 남은 운동 항목 삭제 시 빈칸 리셋
- [ ] 개별 운동 삭제(`onRemove`) 이벤트 처리 시:
  - 현재 섹션의 `exercises.length === 1`인 경우: 배열에서 삭제하지 않고 해당 아이템을 초기화 (`name: ''`, `muscle: null`, `isManualTagged: false`, `sets: [빈 세트]`)
  - `exercises.length > 1`인 경우: 정상 삭제 (`filter`)

### 4. [예외 4] 무게 및 횟수 비정상 입력 차단
- [ ] 키다운(`onKeyDown`) 이벤트에서 원천 차단:
  - 빼기/마이너스 기호 (`-`, `Key-`, `NumpadSubtract`) 입력 시 `e.preventDefault()`
  - 스페이스바 (`Space`) 입력 시 `e.preventDefault()`
  - 무게 필드: 숫자(0-9), 소수점(`.`) 1개까지만 허용
  - 횟수 필드: 오직 정수 숫자(0-9)만 허용
- [ ] 붙여넣기(`onPaste`) 및 `onChange` 시 정규식 마스킹:
  - 무게: `^\d*(\.\d{0,2})?$`
  - 횟수: `^\d*$`

### 5. [예외 5] 필터링 활성화 상태에서 새 운동 추가 시 필터 강제 리셋
- [ ] 화면 하단 플로팅 '운동 추가 (+)' 버튼 및 섹션 내 '운동 추가' 버튼 클릭 시:
  - `filter` 상태를 즉시 `'all'`(전체)로 강제 초기화
  - 추가된 신규 운동이 즉시 화면에 노출되도록 보장

---

## ✅ 완료 기준 (Definition of Done)
1. 운동명이 빈칸일 때 세트 입력칸을 누르면 1.5초간 운동명 칸이 붉게 깜빡이며 포커스가 이동함.
2. 1개 남은 운동을 삭제하면 리스트가 비지 않고 빈칸으로 초기화됨.
3. 무게/횟수 입력칸에 `-`, 스페이스, 문자가 절대 입력되지 않음.
4. '가슴' 필터 상태에서 운동 추가 시 필터가 '전체'로 바뀌며 새 항목이 보임.
