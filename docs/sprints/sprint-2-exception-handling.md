# 🛡️ Sprint 2: PRD 5대 예외 처리 및 방어 로직 완벽 구현

## 📋 스프린트 목표
PRD Section 5에 명시된 5가지 필수 방어 로직을 조건문과 이벤트 핸들러 형태로 빈틈없이 구현하고 검증합니다.

## 🛠️ 세부 작업 항목 (Tasks) 및 진행 현황

### 1. [예외 1] 태그 매칭 실패 및 수동 변경 우선순위 보호
- [x] 딕셔너리 매칭 실패 시 기본 텍스트 `미지정` 표출
- [x] 태그 칩 클릭 시 7개 부위 선택 팝오버 표시
- [x] 수동 변경 시 `isManualTagged: true`로 설정하여 이후 운동명 변경 시에도 태그 보존

### 2. [예외 2] 운동명 누락 시 세트/무게 입력 시도 차단 & 1.5초 레드 깜빡임
- [x] 아코디언 내부의 무게(weight) 및 횟수(reps) 입력 필드 `onFocus` 시 핸들러 연결
- [x] `exercise.name.trim() === ''`인 경우:
  - 입력 필드 포커스 즉시 취소 (`event.preventDefault()`, `event.target.blur()`)
  - 운동명 인풋에 1.5초간 붉은색 테두리 깜빡임(`animate-pulse ring-2 ring-destructive`) 적용
  - 운동명 인풋으로 강제 포커스 이동 (`nameInputRef.current?.focus()`)
  - 인라인 안내 메시지 표시

### 3. [예외 3] 마지막 남은 운동 항목 삭제 시 빈칸 리셋
- [x] 개별 운동 삭제(`onRemove`) 이벤트 처리 시:
  - 현재 섹션의 `exercises.length === 1`인 경우: 배열에서 삭제하지 않고 `resetExerciseItem`을 통해 빈칸(운동명 `""`, 태그 `미지정`, 세트 초기화)으로 리셋
  - `exercises.length > 1`인 경우: 정상 삭제 (`filter`)

### 4. [예외 4] 무게 및 횟수 비정상 입력 차단
- [x] 키다운(`onKeyDown`) 이벤트에서 원천 차단:
  - 빼기/마이너스 기호 (`-`, `Key-`, `NumpadSubtract`) 입력 시 `e.preventDefault()`
  - 스페이스바 (`Space`) 입력 시 `e.preventDefault()`
- [x] 붙여넣기(`onPaste`) 및 `onChange` 시 정규식 마스킹:
  - 무게: `^\d*(\.\d*)?$` (숫자 및 소수점 1개까지)
  - 횟수: `^\d*$` (양의 정수)

### 5. [예외 5] 필터링 활성화 상태에서 새 운동 추가 시 필터 강제 리셋
- [x] 화면 하단 플로팅 '운동 추가 (+)' 버튼 및 섹션 내 '운동 추가' 버튼 클릭 시:
  - `filter` 상태를 즉시 `'all'`(전체)로 강제 초기화하여 신규 항목이 즉시 화면에 노출되도록 보장

## ✅ 완료 검증 (Verification Results)
1. **[예외 1 검증]:** 수동으로 태그를 지정한 항목은 운동명을 지우거나 다시 작성해도 자동 매칭에 의해 덮어써지지 않고 수동 태그가 유지됨.
2. **[예외 2 검증]:** 운동명이 빈칸일 때 세트 무게/횟수 입력칸을 클릭하면 즉시 포커스가 해제되고, 운동명 입력칸이 붉은색으로 1.5초간 점멸하며 포커스가 이동함.
3. **[예외 3 검증]:** 운동 항목이 1개만 남아있을 때 'x' 버튼을 누르면 리스트가 비어버리지 않고 빈칸 상태로 안전하게 리셋됨.
4. **[예외 4 검증]:** 무게/횟수 칸에 '-', 스페이스바, 알파벳, 특수문자를 직접 타이핑하거나 붙여넣기해도 입력되지 않음.
5. **[예외 5 검증]:** 부위 필터가 켜져 있는 상태에서 운동 추가 시 필터가 '전체'로 복귀하며 추가된 항목이 포커스됨.
