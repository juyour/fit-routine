# ⚡ Sprint 3: 인터랙션 강화 및 레이아웃 최적화

## 📋 스프린트 목표
운동 중 빠른 기록을 지원하기 위한 모바일 터치 인터랙션, 드래그앤드롭 순서 변경, 부드러운 아코디언 애니메이션을 최적화합니다.

---

## 🛠️ 세부 작업 항목 (Tasks)

### 1. 드래그 앤 드롭 (DnD) 순서 변경 고도화
- [ ] 데스크톱 마우스 드래그 및 모바일 터치 드래그 지원
- [ ] 드래그 인디케이터 라인 및 드래그 중인 아이템의 시각적 피드백(반투명/그림자 효과)
- [ ] 섹션 내 운동 항목의 인덱스 스왑(Swap) 로직 안전성 검증

### 2. 아코디언 확장 및 세트 관리 인터랙션
- [ ] 아코디언 열림/닫힘 높이 전환 애니메이션 (`grid-rows-[0fr]` -> `grid-rows-[1fr]`)
- [ ] 세트 추가(+) 시 자동 포커스 및 볼륨(총 무게) 실시간 계산 피드백
- [ ] 세트 삭제 시 즉각적인 인덱스 재정렬

### 3. 분할(Split) 선택 및 섹션 탭 연동
- [ ] '무분할', '2분할', '3분할', '4분할', '5분할' 전환 시 부드러운 탭 인터랙션
- [ ] 분할 변경 시 현재 일자(Day) 자동 포커스 및 뷰 리셋
- [ ] 하단 고정 플로팅 버튼(`운동 추가 (+)`)과 활성 섹션 간 원활한 상호작용

---

## ✅ 완료 기준 (Definition of Done)
1. 핸들 아이콘(☰)을 잡고 끌어서 운동 순서를 자유롭게 변경할 수 있음.
2. 운동 항목 터치 시 아코디언이 부드럽게 열리고 세트별 무게/횟수를 즉각 수정할 수 있음.
3. 분할 변경 시 해당 분할의 루틴이 완벽히 렌더링됨.
